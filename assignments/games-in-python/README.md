# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo em que o jogador tenta adivinhar uma palavra oculta, escolhendo uma letra por vez. O jogo deve mostrar o progresso e terminar quando a palavra for descoberta ou as tentativas incorretas acabarem.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar as letras descobertas e as posições ainda ocultas, por exemplo, `_ _ _`.
- Rastrear e informar quantas tentativas incorretas restam.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando vitória ou derrota.
