# 📘 Assignment: Lists and Dictionaries in Python

## 🎯 Objective

Aprenda a organizar coleções de dados com listas e dicionários em Python. Ao final, você combinará essas estruturas para criar e consultar um pequeno catálogo de livros.

## 📝 Tasks

### 🛠️ Create and Explore a List

#### Descrição
Crie uma lista com pelo menos três títulos de livros. Percorra a lista para exibir cada título e permita adicionar mais um título antes de exibir a coleção atualizada.

#### Requisitos
O programa concluído deve:

- Criar uma lista com pelo menos três títulos iniciais
- Usar um loop para exibir cada título, um por linha
- Adicionar um novo título com `append()` e exibir a lista atualizada

### 🛠️ Represent a Book with a Dictionary

#### Descrição
Represente um livro usando um dicionário. Inclua informações que descrevam o livro e exiba cada valor usando sua chave.

#### Requisitos
O programa concluído deve:

- Criar um dicionário com as chaves `title`, `author` e `year`
- Armazenar um valor adequado para cada chave
- Acessar e exibir o título, o autor e o ano usando as chaves correspondentes

### 🛠️ Build a Small Book Catalog

#### Descrição
Combine listas e dicionários para organizar vários livros. Crie uma lista de dicionários e permita localizar um livro pelo título.

#### Requisitos
O programa concluído deve:

- Criar uma lista com pelo menos três dicionários de livros, cada um com `title`, `author` e `year`
- Percorrer a lista e exibir as informações de cada livro
- Procurar um livro pelo título e exibir seus dados quando encontrado
- Exibir uma mensagem clara quando o título procurado não estiver no catálogo
